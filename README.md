# Codex Browser Companion

一个独立、开源、local-first 的 Chrome 侧边栏助手：把当前网页整理成经过隐私检查、可以直接交给 Codex 的高质量上下文。

> [!IMPORTANT]
> 本项目不是 OpenAI 官方扩展，也不隶属于或代表 OpenAI。它不替代官方浏览器控制能力，不包含官方扩展代码，也不连接官方扩展的本机服务。

## 明显的功能提升

- **网页上下文采集**：按需提取标题、URL、描述、选中文本、页面大纲、可见正文和链接。
- **右键发送选中文本**：选中一段内容，右键选择 **Prepare selection for Codex**，直接进入侧边栏预览。
- **6 种提示词模板**：总结、排错、无障碍检查、结构化提取、安全审查和自定义任务。
- **隐私预览与自动脱敏**：复制前展示完整内容；默认遮盖邮箱、Bearer Token、JWT、密钥字段和敏感 URL 参数。
- **抗提示注入边界**：明确将网页快照标记为不可信数据，提醒模型忽略网页中的伪指令。
- **Markdown / JSON 输出**：可复制，也可下载为本地文件。
- **长度与内容可控**：正文上限 2,000–20,000 字符；大纲、链接、选中文本均可单独开关。
- **一键打开 Codex Cloud**：准备好上下文后直接打开 Codex。
- **极小权限面**：没有 `<all_urls>`、浏览记录、Cookie 或后台常驻页面读取权限。

## 安装（开发者模式）

1. 下载或克隆此仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本仓库根目录（包含 `manifest.json` 的文件夹）。
6. 打开任意普通网页，点击工具栏中的扩展按钮。

快捷键默认为 `Alt+Shift+C`，可在 `chrome://extensions/shortcuts` 修改。

## 使用方式

1. 在目标网页点击扩展按钮，然后点击 **Capture current page**。
2. 选择任务模板和需要包含的内容。
3. 在 **Privacy preview** 中检查最终文本及脱敏数量。
4. 复制提示词、下载文件，或打开 Codex Cloud 后手动粘贴。

扩展不会替你自动发送数据。这是刻意的设计：**复制之前，你始终能看到即将离开浏览器的确切内容**。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 只在用户主动操作后临时读取当前页 |
| `scripting` | 注入一次性的本地采集脚本 |
| `sidePanel` | 显示工作区 |
| `storage` | 保存偏好、短暂传递右键选中文本 |
| `contextMenus` | 添加选中文本快捷入口 |

详细说明见 [PRIVACY.md](PRIVACY.md)。

## 本地开发

项目没有运行时第三方依赖。

```powershell
npm test
npm run check
```

- `npm test` 使用 Node 内置测试运行器检查脱敏、格式化和提示注入边界。
- `npm run check` 校验 Manifest V3、禁止广泛 host 权限并检查全部 JavaScript 语法。
- GitHub Actions 会在 push 和 pull request 时重复执行这两项检查。

## 已知限制

- Chrome、Edge 设置页等受保护页面不允许扩展注入脚本。
- `file://` 页面需要用户在扩展详情页主动打开“允许访问文件网址”。
- 自动脱敏是辅助防线，不可能识别所有私人数据；复制前仍应人工检查。
- 网页快照不是完整 DOM、网络日志或截图；涉及视觉布局和运行时问题时，需要补充相应证据。
